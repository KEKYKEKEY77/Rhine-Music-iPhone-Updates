# Rhine Music iPhone 更新源

AltStore Classic → Browse／浏览 → Sources／源 → ＋，粘贴：

`https://raw.githubusercontent.com/KEKYKEKEY77/Rhine-Music-iPhone-Updates/main/source.json`

在源内安装 Rhine Music。后续版本发布后，AltStore 检测更新并通知；在“我的应用”点击更新。
签名安装及更新需要连接运行 AltServer 的电脑（同一局域网或 USB）。免费账号仍须在 7 天内续签。
更新前在 Rhine 导出专辑架备份，保留原 App，并使用同一个 Apple 账号。

此仓库仅提供未签名安装包、更新说明、图标与许可。用户专辑资料和网易云登录信息不随包分发。
每个 Release 的 SHA256SUMS.txt 与 releases.json 记录实际安装包的 SHA-256。

源工程基于 [RonaldDeng / Rhine-Music-Demo](https://github.com/RonaldDeng/Rhine-Music-Demo)
及 [LBEILC / RhineLabUI](https://github.com/LBEILC/RhineLabUI)。保留 MIT 代码署名；非代码素材与第三方依赖分别遵守 [NOTICE.md](NOTICE.md)。
